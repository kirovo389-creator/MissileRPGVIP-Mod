# Countdown Timer Android

A simple native Android countdown timer app written in Java.

## Build APK

The project can be built using GitHub Actions with the workflow in `.github/workflows/build-android.yml`. Open the **Actions** tab, select **Build Android APK**, run the workflow if needed, then download the `countdown-timer-debug-apk` artifact from a successful run.

## Features
- Start, pause, resume, and reset countdown
- Minutes and seconds inputs
- Notification toast when the countdown finishes
